# 0.1.2 — 2026-10-25

## Added

- **Document discovery** supports relevance/date sorting and member-IID filtering; document detail adds independently paged stakeholders with published roles and identities (#11) (#12).
- **Report ballots** expose individual main votes for an explicit point through `ballots: true`, with independent `ballotPage` continuation and revision checks (#13).
- **Historical member discovery** adds explicit `register: "all"`, preserving substring matching, historical UUID identities, and separate source-reported and returned counts; cold requests can reach the normal timeout (#6).
- **Plugin installation** includes Agent Plugins root manifests alongside the Claude Code and Codex overlays.

## Changed

- **Default text pages** start at 8,000 Unicode code points and fit the complete document or speech response, including combined representations and hydrated search items; explicit lengths remain honored (#15).
- **Input guidance** accepts consecutive full-year sessions, names date and speech-mode constraints, clamps positive output ceilings at existing maxima, and normalizes blank document revisions (#17).
- **Packaging and tooling** adopt framework validation, skill guidance, and bundle exclusions; MCPB cleanup retains SDK runtime skill modules while removing development content. Hosted connection and capability documentation now describe the available workflows.

## Fixed

- **Member votes** retain source point-zero records and distinct substantive/motivation ballots sharing vote IDs (#3).
- **Report summaries and party totals** preserve singleton and multiple historical tables, and derive separate party/`avser` counts from complete ballots; missing vote labels leave exact counts unknown (#4).
- **Speech misses** treat exact zero-byte HTTP 200 detail responses as uncached misses, including search hydration (#5).
- **Serving substitutes** use the three published service labels in both member tools (#7).
- **Document text** retains route-specific subtitles and SFS consolidation labels, and exposes readable proposals and notice properties alongside original HTML (#8) (#9).
- **Document search pagination** fits whole rows within a stable remote page, preserving source order, fixed remote page size, complete continuations, and revision checks (#10).
