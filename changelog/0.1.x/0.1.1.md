# 0.1.1 — 2026-10-25

## Added

- **Documents and statutes:** search parliamentary publications, inspect status and linked sections, and retrieve consolidated SFS text with complete text and section continuations.
- **Speeches:** search session-scoped debate headings and retrieve published speech text through get mode.
- **Votes:** read report decisions with party main-vote totals or a member's session main votes, preserving unknown counts and publication states.
- **Members and references:** search member register entries, traverse assignment histories, and resolve official vocabulary from a dated reference snapshot.
- **Retrieval context:** source attribution, revision-checked local continuations, and source warnings appear on both output surfaces; stdio and Streamable HTTP require no API key.

## Fixed

- **Swedish document identifiers** accept source Unicode letters in document retrieval and report vote queries (#1).
