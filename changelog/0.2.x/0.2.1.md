# 0.2.1 — 2026-11-23

## Added

- **`riksdag_search_members` `committee`** returns a committee's current holders, each with `committeeAssignments` current at the source time; **`familyNamePrefix`** matches the start of the source's sort name in either register. An empty committee or family-name response carries only its own explaining notice ([#29](https://github.com/cyanheads/sweden-parliament-mcp-server/issues/29)).
- **`riksdag_get_votes` report mode** returns `chamberStatus` and `decisionDate`, and a notice naming the planned decision date for an undecided report ([#30](https://github.com/cyanheads/sweden-parliament-mcp-server/issues/30)).

## Changed

- **`riksdag_search_documents` `pageSize`** ceiling 50 → 200 and **`riksdag_search_speeches` `limit`** ceiling 20 → 100 ([#31](https://github.com/cyanheads/sweden-parliament-mcp-server/issues/31)).
- **Unknown-code errors** name the caller's input field (`party`, `committee`, `documentType`), `riksdag_search_speeches` `party` included.

## Fixed

- **`riksdag_get_document`** and **`riksdag_get_votes` report mode** no longer re-convert a cached record's HTML; conversions are memoized on the cache entry and count toward its 32 MiB bound ([#25](https://github.com/cyanheads/sweden-parliament-mcp-server/issues/25)).
- **`riksdag_search_speeches`** collapses identical copies of a speech under one retrieval ID into one row with a counting notice (conflicting copies still fail), and get mode decodes the source's doubled-XML detail record ([#27](https://github.com/cyanheads/sweden-parliament-mcp-server/issues/27)).
- **Hydrated `riksdag_search_speeches` rows** keep their list row's `sourceHtmlUrl`, `protocolUrl` and date precision ([#32](https://github.com/cyanheads/sweden-parliament-mcp-server/issues/32)).
- **Committee codes and report designations** typed without their Swedish letter resolve: `fou17` is FöU17, `fou` is FöU ([#28](https://github.com/cyanheads/sweden-parliament-mcp-server/issues/28)).
- **`riksdag_search_documents` deep paging** stops `nextCall` at the page ending on row 10,000, the source's limit, with a narrowing notice. A page ending past it returns its rows up to it; a page starting after it returns empty with a notice and sends no request, instead of failing with HTTP 400.
- **`riksdag_search_documents`** returns each record once instead of failing pages that mix in member-profile, web-page, empty-ID calendar (cancelled entries), single-occurrence calendar or repeated calendar rows; each kind carries a counting notice.
- **Calendar rows in document search**: single-occurrence rows (IDs ending in `-u` and a number) are listed under their event's record ID, which `riksdag_get_document` reads; member-profile, web-page and empty-ID calendar rows are skipped; repeats merge into the record at its first position.
- **Vote coverage** is stated from 2002/03 in `riksdag_list_reference` and the `riksdag_get_votes` standing notice; the source has no vote rows for 1993/94–2001/02.
- **`riksdag_get_votes` report-mode ballots** whose `dok_id` the source publishes empty or absent are counted when report, point and session match, instead of failing `upstream_identity_mismatch`.

## Security

- **Document HTML-to-Markdown conversion time** grows linearly with record size.
