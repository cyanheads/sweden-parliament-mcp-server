# 0.2.0 — 2026-11-15

## Added

- **`riksdag_search_speeches` `relatedDocumentId`** keeps the speeches the source links to a report or interpellation, and **`riksdag_get_document` `relatedSpeechesCall`** is the ready call for `bet` and `ip` records with a session. Riksdagen links a speech only on the segment where its debate starts, so a resumed debate's later segments can lack the link (#22).
- **`riksdag_get_votes` member mode** accepts `report` and `point` (`point` requires `report`), narrowing the member's rows locally with no extra upstream request (#23).
- **`sweden-parliament-guide` skill** published as `skill://sweden-parliament-guide/SKILL.md` in `resources/list`: identifier chains and gates across the `riksdag_*` tools.

## Changed

- **Page size is the caller's limit only**, up to each documented maximum; default text pages are a fixed 8,000 code points, and an oversized row returns whole (#19).
- **`tools/list` weight** drops: continuation `args` are open objects and shared output schemas sit once under `$defs` (#16).
- **Input `pattern`s** on `session`, `dateFrom`/`dateTo`, `memberId`, `documentId`, `speechId` and `report`, and a `sections` enum on `riksdag_get_document`; malformed values are rejected at the schema as `-32602` naming the field (#24).
- **Member vote rows** come in source-timestamp (`systemDate`) order, not vote-date order (#14).

## Removed

- **`truncated`** output field on `riksdag_list_reference`, `riksdag_search_documents`, `riksdag_search_members`, `riksdag_search_speeches` and `riksdag_get_votes`, plus `ballotPage.truncated` and `sectionPages[].truncated`; read `hasMore` and `nextCall` (#19).
- **Member-vote rows' `date`**, which the source never published (#14).
- **`unknown_section`** error reason of `riksdag_get_document`; an unknown section now fails the schema (#24).

## Fixed

- **Report-mode `documentId`** of the wrong type, session or report now fails `invalid_filter` before any vote request (#20).
- **One spelling per identifier**: document IDs uppercase, report designations as published (`FöU1`) (#21).
- **N-series SFS IDs** (`sfs-N2026-7`, `SFS N2026:7`, `N2026:7`) and vote-record IDs (`H6190118-1`) are accepted, and `riksdag_search_documents` with `documentType: sfs` or `votering` no longer fails `upstream_schema_invalid`.
- **Report designations** accept decomposed letters and whitespace around a session prefix's `:` (`2024/25: FöU1`) (#24).
- **Date errors** name `dateFrom` or `dateTo` (#24).
